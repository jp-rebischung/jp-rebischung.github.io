INC-03 Un serveur Linux ne remonte plus dans Zabbix

Tux · Linux« Le service tourne » ne veut pas dire « le service répond ». Ici, l'agent écoutait bien : c'est le pare-feu local qui jetait les demandes.

DemandeAlerte de supervisionJean-Philippe

Zabbix signale que l'agent du serveur VM-syslog-JP n'est plus disponible depuis 15h17 : la connexion TCP n'est plus établie. Dans la collecte de données, l'indicateur de disponibilité de l'hôte est rouge.

TâcheInterroger l'agent depuis le serveur ZabbixJean-Philippe

zabbix_get -s VM-syslog-JP -p 10050 -k agent.version : Connection timed out. Un délai dépassé, c'est un paquet jeté quelque part.

TâcheVérifier le service et l'écouteJean-Philippe

Sur le serveur : systemctl status zabbix-agent2 → actif. Mais un service actif ne prouve pas qu'il répond. ss -tlnp | grep 10050 → l'agent écoute bien sur le port 10050.

TâcheVérifier le pare-feu localJean-Philippe

sudo ufw status numbered : la règle qui autorise le serveur Zabbix sur le port 10050 n'apparaît plus. C'est elle qui manque.

TâcheRemettre la règle et vérifierJean-Philippe

sudo ufw allow from <serveur Zabbix> to any port 10050 proto tcp comment 'Zabbix agent passif'

Depuis le serveur Zabbix, zabbix_get renvoie la version de l'agent ; l'indicateur de l'hôte repasse au vert et le problème passe en résolu à 16h20.

TâcheChercher pourquoi la règle a disparuJean-Philippe

Le journal des commandes sudo montre une session root ouverte vers 15h17, juste avant l'alerte. Il n'enregistre pas ce qui a été tapé dans cette session : il ne permet donc pas de prouver que la règle a été supprimée à ce moment-là. Je le note comme piste, pas comme cause.

SolutionSolution approuvée · ticket closJean-Philippe

Cause : la règle du pare-feu local (ufw) autorisant le serveur Zabbix à joindre l'agent sur le port 10050/tcp avait disparu. Le pare-feu rejetait les demandes, d'où le délai dépassé et l'agent indiqué indisponible.

Correction : règle remise en place, limitée au serveur Zabbix.

Vérification : zabbix_get répond, indicateur de l'hôte au vert, problème résolu dans Zabbix.

Piste à confirmer : pourquoi la règle a disparu. Une session root vers 15h17 est la piste la plus probable, à confirmer avec la personne concernée.

À retenir

Je vérifie dans l'ordre : l'agent répond-il ? le service tourne-t-il ? écoute-t-il ? le pare-feu laisse-t-il passer ? Et j'écris ce qui est prouvé séparément de ce qui est probable.
